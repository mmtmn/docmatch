# Usar a docmatch

Conciliar é comparar documentos que deveriam contar a mesma história. Uma planilha diz
o que deveria entrar; um extrato mostra o que entrou. A docmatch ajuda a encontrar
correspondências e diferenças, com referências para conferir a origem.

Comece com [dois arquivos de exemplo](primeiro-projeto.md). Depois, guarde seu trabalho
em um [projeto](projetos.md) e convide as pessoas que precisam participar.

**Você decide quando gastar.** Antes de uma nova análise, a docmatch apresenta uma
estimativa e um limite para aprovação. Se os arquivos e as regras não mudaram e já existe
um resultado válido, o projeto abre esse resultado.

Um resultado concluído pode conter divergências. Confira as evidências antes de usar
uma sugestão para corrigir seus registros.

Para ligar a docmatch a outro sistema, abra o guia
[Integrar e desenvolver](../../desenvolvedor/src/inicio.md).
