# Experimente com dois arquivos

Use dados inventados para aprender o fluxo. Estes dois CSVs representam três cobranças
e os movimentos de uma conta. Não contêm dados de clientes reais.

<!-- demo-downloads -->

1. Entre na docmatch e confira o nome da **conta** no topo.
2. Abra **Projetos**, escolha **Novo projeto** e dê um nome, como “Meu primeiro fechamento”.
3. Adicione os dois arquivos. Espere a indicação de que estão prontos.
4. Expanda **Documentos** se quiser conferir a lista. O botão de conciliar continua no rodapé.
5. Peça a estimativa, leia o limite de créditos e aprove somente se aceitar esse consumo.
6. Abra o resultado, consulte uma evidência e baixe a planilha.

Os exemplos têm uma diferença de valor e um recebimento ausente para você investigar.
A apresentação dos achados pode variar. O objetivo é aprender a conferir as fontes,
não memorizar uma quantidade de avisos.

Volte ao projeto e tente novamente sem mudar os arquivos ou as regras. Um resultado
concluído e ainda disponível deve ser aberto sem iniciar outra análise.

Se sua permissão for **Apenas adicionar documentos**, você pode enviar os arquivos.
Uma pessoa com acesso completo ao projeto precisa aprovar a análise.
