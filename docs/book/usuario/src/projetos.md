# Salve e volte depois

Um projeto reúne documentos, regras e conciliações de um trabalho. Use nomes que ajudem
a retomar, como “Fechamento de outubro”. Renomear não muda o conteúdo de uma análise.

Espere a confirmação de salvamento antes de fechar. Um arquivo em envio ainda depende
da conexão; se o envio for interrompido, pode ser necessário selecioná-lo novamente.
**Em verificação** significa que ele chegou, mas ainda não está pronto para conciliar.

Ao voltar, escolha a mesma conta e abra o projeto. Os documentos começam recolhidos
para deixar a tela leve. Expanda a lista para conferir todos, remover ou substituir um
arquivo. A lista rola sem levar o botão de conciliação embora.

Substituir cria uma nova versão. O resultado anterior continua ligado aos documentos
que foram usados naquela análise. Mudar nome ou ordem visual não exige nova conciliação;
trocar documentos ou regras pode exigir.

| O que você encontra | Próximo passo |
| --- | --- |
| Resultado válido, sem alterações | Ver o resultado existente. |
| Conciliação em andamento | Acompanhar; fechar a página não cancela o processamento. |
| Documentos ou regras alterados | Pedir nova estimativa e aprovar o limite. |
| Falha ou cancelamento | Conferir o motivo antes de tentar novamente. |
| Resultado indisponível ou expirado | Conferir a retenção; reprocessar exige nova aprovação. |

Arquivar tira um projeto do trabalho ativo. Não aumenta o prazo de armazenamento dos
arquivos. Baixe os resultados que precisa guardar, respeitando os
[prazos do plano](limites.md).
