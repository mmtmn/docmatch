# Privacidade e ajuda

Envie somente os documentos necessários e confira a conta de destino. Compartilhe projetos
com as pessoas que precisam deles. Um convite por e-mail não torna seus projetos privados
visíveis automaticamente.

Os arquivos passam por verificação antes da análise. Se um envio for recusado, leia a
mensagem e confira o formato e o tamanho; mudar apenas a extensão do nome não converte
o conteúdo.

Se uma página travar, reabra o projeto antes de repetir a operação. O estado confirmado
fica no servidor. Um aviso de edição concorrente pede que você carregue a versão mais
recente, para não sobrescrever o trabalho de outra pessoa.

Ao pedir ajuda, informe o que tentou fazer e o identificador da requisição, quando houver.
Não envie senha, chave de API nem documentos completos por um canal público.
