# Créditos e limites

Uma estimativa mostra o consumo esperado e o limite que você está autorizando. Ela não
inicia a conciliação. Quando a análise precisar de uma nova aprovação, você decide se
quer continuar. Os créditos pertencem à conta selecionada.

O tamanho e a quantidade de arquivos aceitos dependem do plano. O projeto permanece
identificável, mas originais e resultados têm prazo de retenção. Abrir ou arquivar o
projeto não reinicia esse prazo. Exporte antes de precisar dos arquivos fora da docmatch.
