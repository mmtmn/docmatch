## Android

As [diretrizes oficiais](https://developer.android.com/distribute/marketing-tools/brand-guidelines#android-robot) permitem reproduzir o robô sob [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/). O crédito exigido deve aparecer na peça publicada, por exemplo no rodapé da página; mantê-lo apenas neste README não satisfaz essa condição:

> The Android robot is reproduced or modified from work created and shared by Google and used according to terms described in the Creative Commons 3.0 Attribution License.

Vincule o nome da licença ao endereço acima. A primeira referência textual deve usar `Android™`; inclua também `Android is a trademark of Google LLC.` no crédito.

A mesma página exige revisão e aprovação da equipe de marca do Android para peças que incluam ou mencionem suas marcas. Este download não comprova essa aprovação; nenhuma solicitação foi enviada. A licença do robô não equivale a autorização para o wordmark Android. Não há badge Google Play nesta pasta, pois não foi confirmada uma página de distribuição.

## GitHub

O [Brand Toolkit oficial](https://brand.github.com/foundations/logo#legal) permite o Invertocat como botão que leva a um perfil ou projeto no GitHub e permite logos vinculando ao próprio GitHub. É uma permissão de uso da marca, não uma licença de software livre. As marcas e a arte continuam pertencendo ao GitHub, Inc.; a página não exige um texto específico de crédito para esse uso permitido.

Os dois SVGs já incluem a área de respiro oficial. Preserve proporção, cores, desenho e espaço; escolha preto ou branco conforme o fundo, sem filtros, recortes ou efeitos. A marca deve ser secundária à do DocMatch, com contexto textual claro, sem sugerir parceria ou endosso.

O repositório do DocMatch permanece privado. Não anuncie código aberto nem altere a visibilidade para fazer um botão funcionar. Até haver um destino público apropriado, mostre o estado real de disponibilidade; se usar um link genérico ao GitHub, identifique-o como tal.

## iOS / App Store

Nenhuma arte Apple foi adicionada. As [diretrizes da App Store, seção Badge Use](https://developer.apple.com/app-store/marketing/guidelines/#section-badges), proíbem o logo Apple isolado. Os badges oficiais representam download ou pré-venda efetivamente disponível. A [documentação de pré-vendas](https://developer.apple.com/app-store/pre-orders/) exige submissão, revisão e publicação da página antes de oferecer a pré-venda.

Sem uma página confirmada na App Store, use texto normal como `iOS — em breve`, sem desenhar um logo nem simular um badge. Isso é uma indicação de disponibilidade futura, não uma arte aprovada pela Apple. Para copy de marketing de um aplicativo, a Apple prefere o nome do aparelho, por exemplo `para iPhone — em breve`, em vez do nome do sistema. Só afirme compatibilidade já confirmada; veja também [Compatibility nas diretrizes de marcas](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html).

Quando existir uma página elegível, obtenha o badge oficial pelos [App Store Marketing Tools](https://toolbox.marketingtools.apple.com/), revise as condições aplicáveis e aponte diretamente à página real do aplicativo.
